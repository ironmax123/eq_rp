# 地震発生時 pin 一時表示 実装計画

## 目的

地震発生時に、ユーザーがリストをタップしなくても震源地の pin が数分間表示されるようにする。

## 現状

- `app/lib/provider/eq/provider.dart` が2秒ごとに `/v1/eq/<timestamp>` を polling している。
- リアルタイム地震が取得できた場合、`HomeScreenViewModel.build()` が履歴一覧の先頭にその地震を追加している。
- `app/lib/ui/home/screen.dart` の震源 pin は `selectedEarthquake != null` の時だけ表示される。
- そのため、地震が発生して一覧には出ても、ユーザーがリストをタップしない限り pin は表示されない。

## 実装方針

リアルタイム地震を取得した時に ViewModel 側で自動的に `selectedEarthquake` に設定し、一定時間経過後に自動解除する。

表示時間は「数分間」という要件に合わせ、まずは3分とする。これは既存 API 側で「地震検知から3分経過で履歴追加」している挙動とも合わせやすい。

## 変更対象

### `app/lib/ui/home/view_model.dart`

- `dart:async` を import する。
- ViewModel に自動 pin 表示用の `Timer?` を保持する。
- `build()` 内で `eqProvider` のリアルタイム地震を検知した時、未選択または別 ID の地震なら `selectedEarthquake` に自動設定する。
- 自動設定した地震は3分後に `selectedEarthquake` を解除する。
- ユーザーがリストで地震を選択した場合は、手動選択を優先し、自動解除タイマーの扱いが不自然にならないよう既存の `selectEarthquake` / `clearSelection` でタイマーを整理する。

### `app/lib/ui/home/screen.dart`

- 既存の pin 表示ロジックは `selectedEarthquake` を使っているため、大きな変更は不要。
- 必要があればコメントを「リストタップ時のみ」から「選択中の地震」に修正する。

## 注意点

- `japan_maps` の pin は地図上の座標に直接配置されているわけではなく、地図を震源地にセンタリングしたうえで画面中央に重ねている。
- 既存の `AbsorbPointer` により、pin 表示中は地図操作を止めてズレを防ぐ設計を維持する。
- リアルタイム地震が3分以内に同じ ID で再取得されても、タイマーを無駄に作り直さない。

## 確認方法

- `dart format app/lib/ui/home/view_model.dart app/lib/ui/home/screen.dart`
- `dart analyze`
- 可能であればローカル API 起動後、リアルタイム地震データまたは demo API のデータで、一覧追加と同時に pin が表示されることを確認する。
