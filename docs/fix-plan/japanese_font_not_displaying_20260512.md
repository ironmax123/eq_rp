# ラズパイでの日本語文字化け（表示不可）修正計画書

## 概要
Raspberry Pi上でFlutterアプリケーションを実行した際、日本語が正しく表示されない（四角い豆腐のような文字になる）問題の解決策を提案します。

## 背景・原因の分析
FlutterのLinux向けビルドは、テキストの描画にOSシステムにインストールされているフォント（fontconfig）に依存します。
Raspberry Pi OS（特にデフォルト状態やLite版からGUIを入れた環境など）では、日本語に対応したフォントがインストールされていないことが多く、その結果、日本語のグリフが見つからずに文字化けが発生します。

## 修正・対策の選択肢

この問題に対するアプローチは大きく2つあります。今回はアプリケーションの用途と環境を考慮し、**アプローチA（システムへのフォントインストール）**を推奨します。

### アプローチA: システム環境に日本語フォントをインストールする（推奨）
Raspberry PiのOS自体に日本語フォントを追加します。
- **メリット**: アプリケーションのビルドサイズが大きくならず、ラズパイ上の他のツールでも日本語が正常に表示されるようになります。
- **デメリット**: 実行前にラズパイ側でコマンドを1つ実行する手間が増えます。
- **対応内容**: `docs/linux_run_guide.md` にフォントインストール手順（`sudo apt install fonts-noto-cjk`）を追記します。

### アプローチB: アプリ内にフォントを内包する（バンドル）
Flutterアプリ内に日本語フォント（Noto Sans JPなど）を含め、コード内でデフォルトフォントとして指定します。
- **メリット**: どのラズパイ・Linux環境に持っていっても、環境構築なしで確実に日本語が表示されます。
- **デメリット**: アプリケーションのサイズが数MB〜十数MB増加します。
- **対応内容**: `pubspec.yaml` で `google_fonts` パッケージを追加し、`main.dart` のテーマ設定に組み込む、またはフォントファイルをダウンロードしてアセットとして追加します。

## 修正計画（アプローチAを採用する場合）

1. **ドキュメントの修正**:
   `docs/linux_run_guide.md` の「必要なライブラリのインストール」セクションに、日本語フォントパッケージ（`fonts-noto-cjk` または `fonts-ipafont` など）のインストール手順を追記します。

#### [MODIFY] [docs/linux_run_guide.md](file:///Users/eitanakgaichi/eq_rp/docs/linux_run_guide.md)
- `sudo apt install libgtk-3-0 libblkid1 liblzma5` に加えて、`fonts-noto-cjk` をインストールする手順を記載。

## 検証計画
- ドキュメント追記後、ユーザーにラズパイ側で `sudo apt install fonts-noto-cjk` を実行してもらい、アプリを再起動して日本語が正しく表示されるか確認していただきます。
