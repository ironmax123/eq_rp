# 震源深さ表示追加 実装計画書

## 1. 目的
地震一覧では現在、震源名、発生日時、マグニチュード、最大震度は確認できますが、震源の深さが表示されていません。
既存レスポンスには `epicenter.depth` が含まれているため、一覧上で深さを確認できるようにして、地震情報の視認性を上げます。

## 2. 現状整理
- `app/lib/model/earthquake.dart` の `Epicenter` には `depth` フィールドが定義済みです。
- `app/lib/model/earthquake.g.dart` でも `depth` の JSON 変換は実装済みです。
- `app/lib/ui/home/widget/list.dart` では一覧カード内に `M{magnitude}` は表示している一方、深さ表示は未実装です。

## 3. 実装方針
- 表示追加のみで完結させ、API やデータモデルの変更は行いません。
- 一覧カード下部のメタ情報行に `深さXXkm` を追加し、既存の `M{magnitude}` と並べて表示します。
- 津波表示が有効なケースでも横並びが破綻しにくいよう、既存レイアウトの余白だけを最小限調整します。

## 4. 変更対象

### `app/lib/ui/home/widget/list.dart`
- 一覧カードのメタ情報行に `深さ${eq.epicenter.depth}km` を追加
- `M` 表示と深さ表示の間に適切な余白を追加
- 既存の津波バッジとの並び順と視認性を維持

## 5. 実装手順
1. 一覧カードのメタ情報行の構造を見直し、`M` と深さを同列で表示する
2. 長い震源名や津波バッジ表示時にもレイアウトが崩れにくいことを確認する
3. 必要であれば Flutter formatter を実行し、差分を整える

## 6. 確認項目
- 各地震カードに `深さXXkm` が表示されること
- 深さ 0 のデータでも表示が不自然にならないこと
- 津波バッジが出るケースでも横並び表示が崩れないこと
- 既存の選択ハイライトやタップ挙動に影響がないこと

## 7. レビュー依頼事項
- 深さ表示位置を一覧カード内の `M` 行に追加する方針で問題ないか
- 表記を `深さXXkm` とする方針で問題ないか

> [!IMPORTANT]
> 承認いただき次第、コード変更に着手します。
