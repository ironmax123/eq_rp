# 地震ごとの都道府県色分け機能 実装計画書

## 1. 目的
現在、APIからのレスポンスデータにおいて地域ごとの震度情報（`areas`）が空配列となっているため、Flutterアプリ側で都道府県の色分けができていません。
P2P等の外部APIに頼らず、緊急地震速報（EEW）および気象庁履歴の「震源位置」と「マグニチュード」から自前で各都道府県の震度を予測・算出し、APIレスポンスに含めるように改修します。

## 2. 実装方針（機械学習モデルの導入を見据えた段階的実装）
過去のCSVデータを用いた機械学習モデルの構築を目指しますが、まずはシステムに予測の枠組みを組み込み、色塗りを機能させるための「フェーズ1」として実装を行います。

### 段階的アプローチ
- **フェーズ1（今回実装）**: Pythonのバックエンド側に「距離減衰式（簡易物理モデル）」を用いた予測ロジックを実装します。全都道府県庁所在地の緯度経度を持ち、震源からの距離とマグニチュードから各都道府県の予想震度を計算して `areas` にセットします。これでP2Pに頼らず最速で色塗りが機能するようになります。
- **フェーズ2（後日）**: 過去のCSVデータ（教師データ）を収集し、機械学習モデル（ランダムフォレスト等）を学習させます。
- **フェーズ3（後日）**: 学習済みモデルをフェーズ1のロジックと差し替え、より高精度なAIベースの予測機能にアップグレードします。

## 3. 具体的な実装内容（フェーズ1）

### [NEW] `api/src/services/predict_service.py`
震度予測を行うコアロジックを新規作成します。
- 全47都道府県庁所在地の緯度・経度リストの定数定義
- 入力：震源の緯度・経度・深さ・マグニチュード
- 処理：各都道府県庁所在地と震源との距離を算出し、距離減衰の簡易式（例: マグニチュードと距離の1次式、または気象庁経験式の近似）を用いて予想震度（1〜7）を計算
- 出力：`[{"name": "北海道", "intensity": "4"}, ...]` のような、Flutter側で処理可能な `areas` リストの形式

### [MODIFY] `api/src/schemas/eq_schemas.py` & `jma_schemas.py`
APIのレスポンススキーマを構築する箇所で、新たに作成した予測サービスを呼び出します。
- EEW (`eq_schemas.py`) および 履歴 (`jma_schemas.py`) の両方において、`areas: []` となっている部分を `predict_service.predict_intensities(...)` を呼び出して埋めるように修正します。
