# マップピンのズレと選択状態解除に関する修正計画

## 発生している問題（バグの内容）
1. ピンを表示した状態でマップを動かすと、ピンがマップ上の震源地からズレて画面に固定されたままになってしまう。
2. 一度地震を選択してピンを表示させた後、選択状態を解除する方法がない。

## 考えられる原因
1. **マップとピンのズレ**
   使用している地図パッケージ（`japan_maps`）の `JapanColorMapsWidget` には、地図に連動して動くピン（マーカー）を描画する仕組みが備わっていません。
   そのため現状のコードでは、地図ウィジェットの上に `Stack` を使って画面の中央にピンアイコンを直接配置しています。ユーザーが地図をドラッグして動かすと、地図だけが動き、ピンは画面中央に固定されたままになるためズレてしまいます。
2. **選択状態の解除**
   ViewModelには `clearSelection()` が用意されていますが、リスト項目を再度タップした時の処理や、解除用ボタンといったUI側からの呼び出しが実装されていません。

## 修正計画

以下の2点の改修を行います。

### 1. 地震選択中（ピン表示中）のマップ操作無効化
根本的にピンを地図に完全に追従させるには、パッケージの仕様上複雑な改修が必要になります。
そこで、**「地震が選択されピンが表示されている間は、マップ自体のドラッグ操作やズーム操作を一時的に無効化する」** という対策を実施します。
* 具体的には `JapanColorMapsWidget` を `AbsorbPointer` でラップし、地震選択中のみ操作をブロックします。
* これにより、震源地が常に画面の中央に固定されるため、ピンと地図がズレる現象を防ぐことができます。

### 2. 選択状態を解除する機能の追加
直感的に選択状態を解除できるように、以下の2つの方法を追加します。
* **リストのトグル選択**:
  リスト（`EqListWidget`）で、現在選択中の地震と同じものをもう一度タップした場合は `clearSelection()` を呼び出して選択を解除するようにします。
* **選択解除（閉じる）ボタンの追加**:
  マップ上（例えば右上）に、地震が選択されている時のみ表示される「×（閉じる）」ボタンを追加し、それをタップすることで選択を解除できるようにします。

## 変更対象のファイル

#### [MODIFY] `app/lib/ui/home/screen.dart`
* `JapanColorMapsWidget` を `AbsorbPointer` で囲み、`selected != null` の場合は操作を無効化する。
* `Stack` 内に、選択解除用の「閉じる（×）」ボタン（またはアイコンボタン）を追加する。
* リストの `onTap` 処理において、既に選択中の地震（IDが一致するもの）をタップした場合は `vm.clearSelection()` を呼ぶように条件分岐を追加。
