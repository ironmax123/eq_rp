# ブザー音列短縮ミス修正 修正計画書

## 現状
`example-code/1_output/2.2_PassiveBuzzer_zero.py` を参考に `api/main.py` のブザー通知を実装したが、実装時にサンプルの音列全体ではなく冒頭 6 要素だけを `BUZZER_TUNE` として切り出してしまっている。

その後、Thonny 確認用の `api/buzzer.py` も `api/main.py` に合わせたため、結果として FastAPI 実行時も Thonny 確認時も、参考コードとは異なる短縮された音になっている。

## 原因
「参考コードのブザー音を使う」という要件に対して、こちらが勝手に「短い通知音にする」と判断し、音列を短縮したこと。

これは要件と異なる実装であり、修正が必要。

## 対策
`example-code/1_output/2.2_PassiveBuzzer_zero.py` の `tune` と同じ音列を、以下の 2 箇所に反映する。

1. `api/main.py` の `BUZZER_TUNE`
2. `api/buzzer.py` の `TUNE`

これにより、FastAPI の地震モード遷移時に鳴る音と、Thonny で `api/buzzer.py` を実行して確認する音を一致させる。

## 修正予定ファイル
- `api/main.py`
- `api/buzzer.py`

## 修正内容
現在の短縮音列:

```python
[
    ("C#4", 0.2),
    ("D4", 0.2),
    (None, 0.2),
    ("Eb4", 0.2),
    ("E4", 0.2),
    (None, 0.6),
]
```

これを参考コードと同じフル音列に戻す。

## 確認方法
1. Thonny で `example-code/1_output/2.2_PassiveBuzzer_zero.py` を実行する。
2. Thonny で `api/buzzer.py` を実行する。
3. 2 つの音列が同じであることを確認する。
4. `api/main.py` の `BUZZER_TUNE` と `api/buzzer.py` の `TUNE` が同じであることを確認する。

構文確認:

```bash
PYTHONPYCACHEPREFIX=/private/tmp/eq_rp_pycache python3 -m py_compile api/main.py api/buzzer.py
```
