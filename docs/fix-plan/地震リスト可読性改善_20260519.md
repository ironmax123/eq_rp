# 地震リスト可読性改善 修正計画

## 1. 考えられる原因

### 情報の強弱が弱い
`app/lib/ui/home/widget/list.dart` では、震源名以外の情報も近い文字色とサイズで並んでおり、一覧として見たときに「まず何を見るべきか」が伝わりにくい状態です。発生日時、マグニチュード、深さ、津波有無が同じ行や近い強度で配置されているため、視線誘導が弱くなっています。

### 背景色に対する文字コントラストが安定していない
カード背景は `IntensityColor.fromIntensity(eq.maxIntensity)` をベースにした震度色になっており、震度ごとに明度差があります。一方で文字色は主に `Colors.white` / `Colors.white70` の固定値なので、背景色によっては文字の抜けが弱くなり、読みづらさが発生しやすいです。
なお、この背景色自体は気象庁準拠のため変更対象にせず、文字側とレイアウト側で可読性を改善します。

### メタ情報の区切りが曖昧
発生日時、マグニチュード、深さなどの補助情報にラベル性やグルーピングが少なく、一覧として見た際に各値の意味を瞬時に把握しづらい構成です。特に `M` と `深さ` は数値情報としては重要ですが、視覚的なまとまりが弱いです。

### 余白と行構成が詰まり気味
カード内の縦余白と行間が小さめで、震源名が長いケースや津波バッジが出るケースでは、情報が密集して見えやすくなっています。結果として、一件ごとの情報の塊が見分けづらくなります。

## 2. 対策

### 情報の優先順位を明確にする
- 1行目は「震源名」と「最大震度」を主役として維持する
- 2行目以降は補助情報として整理し、日時と数値情報を分ける
- 文字サイズ、太さ、色の差で主情報と補助情報を明確に分離する

### メタ情報を整理して見出し性を持たせる
- `M4.2`、`深さ40km` のような値だけでなく、必要に応じて `M` と `深さ` のまとまりが判別しやすいレイアウトにする
- 補助情報は横並びに詰め込みすぎず、必要であれば `Wrap` や複数行化で崩れにくくする
- 津波表示はバッジとして残しつつ、数値情報とぶつからない配置にする

### コントラストを改善する
- 背景色は変更せず、文字色やバッジ背景色の調整で視認性を上げる
- 少なくとも日時や補助情報が背景に埋もれにくい文字強度へ寄せる

### 余白を調整する
- カード内の上下左右余白を少し広げ、1件ごとの情報ブロックを分離しやすくする
- 行間と要素間スペースを見直し、詰まって見える印象を減らす

## 3. 修正計画

### 対象ファイル
- `app/lib/ui/home/widget/list.dart`

### 実施内容
1. 一覧カードの情報構造を見直し、震源名・最大震度・日時・数値情報の優先順位を整理する
2. 補助情報行のレイアウトを調整し、`M`、深さ、津波情報の視認性を改善する
3. 背景色は維持したまま、読みづらい文字色や装飾があれば見直す
4. 余白、行間、バッジサイズを再調整し、一覧としてスキャンしやすい見た目に整える

## 4. 修正時の注意点
- 既存のタップ挙動、選択ハイライト、震度色ベースのカード表現は維持する
- 気象庁準拠の背景色は変更しない
- 長い震源名でも省略表示が破綻しないようにする
- 津波フラグの有無で高さや横幅が不自然に崩れないようにする
- モバイル表示を前提に、横幅不足時の折り返しや詰まりを考慮する

## 5. 期待する改善結果
- 一覧を流し見したときに、震源名、最大震度、発生日時、深さが瞬時に把握できる
- 背景色が変わっても文字が埋もれにくい
- 長い震源名や津波表示があっても、情報が詰まって見えない

> 承認いただき次第、この修正計画に沿って `list.dart` の可読性改善を実施します。
