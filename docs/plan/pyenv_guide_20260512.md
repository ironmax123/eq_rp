# pyenv実行方法ドキュメント作成計画書

## 概要
開発環境においてPythonのバージョン管理を容易にするため、`pyenv`の基本的な実行方法と本プロジェクトでの利用方法をまとめたドキュメントを作成します。

## 背景
本プロジェクトのバックエンド（`api`ディレクトリ）では、`.python-version`ファイルによってPython 3.11.10の使用が指定されています。開発者がスムーズに環境構築を行えるよう、`pyenv`の操作手順を明文化する必要があります。

## 修正・変更内容
1. `docs/pyenv_guide.md` の新規作成
   - `pyenv`のインストール（Mac/Homebrew）
   - 基本的なコマンド（install, versions, global, local）
   - シェル設定（.zshrc等への追記内容）
   - 本プロジェクトでの適用例（`api`ディレクトリでの挙動）
