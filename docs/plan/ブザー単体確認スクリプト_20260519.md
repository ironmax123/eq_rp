# ブザー単体確認スクリプト 実装計画書

## 目的
Thonny でブザー音を単体確認できる `buzzer.py` を作成する。

今回の目的は `api/main.py` の責務分離ではなく、FastAPI とは独立して「ブザーが鳴るか」「音程・リズムが意図通りか」を確認できる実行用スクリプトを用意すること。

## 実装内容

### 1. `api/buzzer.py` を新規作成
`example-code/1_output/2.2_PassiveBuzzer_zero.py` を参考に、Thonny から直接実行できるスクリプトを作る。

主な内容:

- `gpiozero.TonalBuzzer` を使用
- GPIO pin はサンプルに合わせて `17`
- NHK風通知音の `TUNE` を定義
- `play(tune)` 関数で順番に音を鳴らす
- `KeyboardInterrupt` 時に安全に停止
- 再生後に `stop()` と `close()` を呼ぶ

### 2. `main.py` は変更しない
今回の要望は Thonny での音確認用ファイル作成なので、`api/main.py` は触らない。

### 3. 実行方法
Raspberry Pi 上の Thonny で `api/buzzer.py` を開いて実行する。

または CLI なら:

```bash
cd api
python buzzer.py
```

## 修正予定ファイル
- `api/buzzer.py`

## 確認方法
1. Raspberry Pi にパッシブブザーを GPIO17 に接続する。
2. Thonny で `api/buzzer.py` を開く。
3. 実行して通知音が鳴ることを確認する。
4. Ctrl+C または停止ボタンで止めた場合にブザーが鳴りっぱなしにならないことを確認する。

## 注意点
- `gpiozero` が入っていない環境では実行できない。
- Thonny の Python 環境に `gpiozero` が入っている必要がある。
- Raspberry Pi 以外の Mac などでは GPIO がないため動作確認対象外。
