# 地震速報（EEW）時のAPI動作仕様

Python API (`/v1/eq/{timestamp}`) における、地震検知時（地震モード）の動作仕様について記述します。

## 状態遷移

本APIは通常時と地震検知時で動作モードが異なります。状態は内部のキャッシュステートとして保持されています。

1. **通常モード**
   - リクエストのたびに強震モニタ（K-moni）から最新のデータをフェッチします。
   - 取得したレスポンス内に地震データ（`earthquakes`）が存在する場合、**「地震モード（キャッシュモード）」**に移行します。

2. **地震モード（キャッシュモード）**
   - 地震検知から**10分間**継続します。
   - 10分経過後のリクエスト時に、通常モードへ戻ります。

## 地震モード中の動作

地震モード中は、外部API（K-moni）への過剰なリクエストを防ぎつつ、一定のタイミングで履歴保存等を行います。

- **キャッシュの利用（1分間隔のフェッチ）**
  - 前回のデータフェッチから**1分未満**の場合は、キャッシュされたデータをそのまま返却します。
  - 1分以上経過している場合は、再度K-moniからデータをフェッチしてキャッシュを更新します。

- **地震履歴への保存**
  - 最初に地震を検知した時刻から**3分以上**経過したタイミングで再フェッチが行われた際、未保存であれば取得した地震データのうち最初の要素を**履歴（history）に追加**します。
  - 履歴追加は1つの地震イベントにつき1度だけ実行されます。

## ロジックの所在

該当する処理は `api/src/services/eq_service.py` の `eq_service` 関数内に実装されています。
