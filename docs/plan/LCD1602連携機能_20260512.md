# LCD1602連携機能 実装計画書

## 目的
緊急地震速報（EEW）が発生している（`is_eq_mode` が `True` の）場合、Raspberry Piに接続されたLCD1602ディスプレイに地震情報を表示する機能を追加する。

## 実装内容
`api/main.py` に以下の変更・追加を行う。

1. **LCD1602モジュールのインポート**
   - `import LCD1602` を追加する。ローカル環境でのインポートエラーは無視する仕様とするため、`try-except` ブロックを用いてインポートを試み、失敗した場合（Raspberry Pi環境外の場合）はダミーとして動作をスキップまたはログ出力のみ行うようにする（あるいはユーザの指示通り単純にインポートし、エラーを無視するような構造とする）。

2. **背景タスク（バックグラウンドループ）の作成**
   - `asyncio` を用いて、定期的に（例: 1秒ごと）EEWの発生状態を確認する非同期タスク `lcd_update_task` を作成する。
   - `src.repository.kmoni_cache_repository` から `get_cache_state()` を呼び出し、`state.is_eq_mode` の値を監視する。

3. **LCD表示の制御ロジック**
   - **地震モード時 (`is_eq_mode == True`)**:
     - `state.kmoni_cache_data` に格納されている地震データから、震央地名（`epicenter.name`）や最大震度（`maxIntensity`）等を取得。
     - 16x2の文字幅に合わせて整形し、`LCD1602.write(x, y, text)` を用いて出力する。
   - **通常時 (`is_eq_mode == False`)**:
     - 待機中であることが明確にわかるメッセージ（例: `Status: Standby `, `No Earthquake   ` など）をLCDに表示します。

4. **FastAPIライフサイクルへの組み込み**
   - `lifespan` 起動時に `LCD1602.init(0x27, 1)` を実行する（LCDが利用可能な場合）。
   - 同時にバックグラウンドタスクを起動する。

## 懸念点・確認事項
- LCDモジュールの `LCD1602.py` 側に `clear` などのメソッドがあるか不明なため、文字表示をクリアする際は空白16文字で上書きする方式を採用します。
