# pyenvトラブルシューティング（ラズパイ版）計画書

## 概要
`pyenv install` が Raspberry Pi で停止したように見える問題（`patching file setup.py` 等で止まる現象）への対策をドキュメントに追加します。

## 背景
Raspberry Pi は PC に比べて CPU やディスク I/O の性能が低いため、Python のビルド（コンパイル）には非常に時間がかかります。特に `patching file...` は初期段階ですが、ここで止まっているように見えるのは、多くの場合単に処理に時間がかかっているか、リソース不足によるものです。

## 修正・変更内容
1. `docs/pyenv_guide.md` に「Raspberry Pi での注意点・トラブルシューティング」セクションを追加
   - **実行時間の目安**: 30分〜1時間以上かかる可能性があることの明記。
   - **詳細ログの表示**: `pyenv install -v` コマンドの推奨。
   - **リソース監視**: `htop` 等での確認方法。
   - **スワップメモリの増設**: メモリ不足対策としてのスワップ増設手順の紹介。
