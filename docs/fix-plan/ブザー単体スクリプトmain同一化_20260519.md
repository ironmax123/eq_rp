# ブザー単体スクリプトmain同一化 修正計画書

## 現状
`api/buzzer.py` は `example-code/1_output/2.2_PassiveBuzzer_zero.py` と同じ長い音列になっている。

一方で、`api/main.py` に組み込んだブザー通知は短い `BUZZER_TUNE` を使っている。

そのため、Thonny で `api/buzzer.py` を実行しても、FastAPI 実行時に鳴る音の確認になっていない。

## 原因
単体確認スクリプトの目的を「サンプル音の再現」と誤って扱ったため。

本来必要なのは、`api/main.py` と同じ通知音を `api/buzzer.py` で単体確認できること。

## 対策
`api/buzzer.py` の音列を `api/main.py` の `BUZZER_TUNE` と同じにする。

`api/main.py` 側の現在の音列:

```python
BUZZER_TUNE = [
    ("C#4", 0.2),
    ("D4", 0.2),
    (None, 0.2),
    ("Eb4", 0.2),
    ("E4", 0.2),
    (None, 0.6),
]
```

## 修正内容
1. `api/buzzer.py` の `TUNE` を `api/main.py` の `BUZZER_TUNE` と同じ短い音列に変更する。
2. `api/main.py` は変更しない。
3. Thonny で `api/buzzer.py` を実行すれば、FastAPI の地震モード遷移時に鳴る音と同じ音を確認できるようにする。

## 修正予定ファイル
- `api/buzzer.py`

## 確認方法
構文確認:

```bash
PYTHONPYCACHEPREFIX=/private/tmp/eq_rp_pycache python3 -m py_compile api/buzzer.py
```

動作確認:
1. Thonny で `api/buzzer.py` を開く。
2. 実行して、`api/main.py` の `BUZZER_TUNE` と同じ短い通知音が鳴ることを確認する。
